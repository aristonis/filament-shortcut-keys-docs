# الإعدادات

ملف الإعدادات اختياري. لا تنشره إلا عندما تحتاج إلى تغيير قيمة افتراضية:

```bash
php artisan vendor:publish --tag="filament-shortcut-keys-config"
```

ينسخ هذا الملف `config/shortcut-keys.php` إلى تطبيقك. تُقرأ كل قيمة وقت الاستدعاء، لذا يسري التغيير
عند التصيير التالي للصفحة. ومع إعدادات مخزّنة مؤقتًا في بيئة الإنتاج، شغّل `php artisan
config:cache` (أو `config:clear`) بعد تعديله.

## الملف كاملًا

```php
return [
    // 'personal' lets each admin fork and remap their own keys; 'locked' uses one shared map.
    'customization' => 'personal',

    // How each set's letters are pressed.
    'modifiers' => [
        'navigation' => ['g'],
        'global' => [],
        'table' => [],
        'row-action' => [],
        'custom' => ['g'],
    ],

    // Who may edit the panel's shared presets. null denies everyone.
    'authorize' => null,

    // Pin or drop a shortcut from code, keyed by target identity.
    'overlay' => [],

    // Seconds to cache the panel-wide keymap.
    'cache' => [
        'ttl' => 86400,
    ],
];
```

## customization

`'personal'` (الافتراضي) أو `'locked'`. انظر [السماح للمشرفين بالتخصيص](customization.md#personal-and-locked).

## modifiers

كيف تُضغط أحرف كل مجموعة. المجموعات هي `navigation` و`global` (إجراءات الترويسة) و`table`
و`row-action` و`custom`. تأخذ كلٌّ منها قائمة من الرموز (`tokens`):

| القيمة | المعنى |
| --- | --- |
| `['g']` | مفتاح بادئة: اضغط `G`، وارفع إصبعك، ثم الحرف. أي حرف صغير مفرد يصلح. |
| `[]` | مفاتيح مجرّدة. |
| `['alt']`، `['ctrl', 'shift']`، ... | مفاتيح تعديل ممسوكة. الرموز: `ctrl` و`alt` و`shift` و`meta`. |

القيم الافتراضية تتجنّب مفاتيح التعديل الممسوكة عن قصد: انظر
[لماذا لا يُضغط أي مفتاح مع الإمساك افتراضيًا](shortcuts.md#why-nothing-is-held-by-default).

القواعد:

- **إزالة مجموعة من القائمة تعيد مخططها المدمج.** فهي لا تحوّل المجموعة إلى مفاتيح
  مجرّدة، لذا فإن حذف سطر هو الطريقة الآمنة للتراجع عن تغيير.
- **المجموعتان على المخطط نفسه تتشاركان مجمّع أحرف واحدًا**، فلا يمكن أن تحصلا أبدًا على المفتاح نفسه.
  افتراضيًا يتشارك التنقّل والمخصّصة مجمّع `G`، وتتشارك إجراءات الترويسة والصفوف المجمّع المجرّد.
- **مفتاح البادئة محجوز بين المفاتيح المجرّدة**، فلا يستطيع أي اختصار مجرّد أخذه.
- `mod` غير مدعوم: فكونه يعني `Ctrl` أو `Cmd` يعتمد على منصّة المستخدم، بينما
  تُبنى خريطة المفاتيح على الخادم.

الإعدادات التالية ترمي استثناءً عند تصيير صفحة من صفحات اللوحة، مع رسالة تسمّي المشكلة:

| الخطأ | مثال |
| --- | --- |
| رمز غير معروف | `['option']`، أو `['mod']`، أو بادئة بحرف كبير `['G']` |
| بادئة ممزوجة برموز أخرى | `['g', 'shift']` |
| بادئة هي أحد مفاتيح الجدول المجرّدة | `'navigation' => ['j']` بينما الجدول على مفاتيح مجرّدة |
| إجراءات الترويسة أو الصفوف على مفاتيح التنقّل نفسها أو مفاتيح الروابط المخصّصة | `'global' => ['g']`، أو `'row-action' => []` مع `'navigation' => []` |

القاعدة الأخيرة موجودة لأن أحرف الفئتين تُسنَد كلٌّ على حدة، فقد يمنح مجمّع مشترك مفتاحًا
واحدًا لاختصارين. ويمكن أن تكون لإجراءات الترويسة والصفوف مفاتيح خاصة بها، مثل
`'global' => ['a']`.

تُضبط المفاتيح مرة واحدة لكل عملية نشر، للجميع. لا يوجد مخطط مفاتيح تعديل خاص بكل مشرف.

## authorize

من يحقّ له تأليف الإعدادات المسبقة المشتركة: `null` (رفض الجميع، وهو الافتراضي)، أو اسم قدرة `Gate`، أو
دالة `closure` بالشكل `fn (?Authenticatable $user, string $panelId): bool`. فضّل القدرة، لأن الـ `closure`
يعطّل `php artisan config:cache`. انظر [بوابة التأليف](customization.md#the-authoring-gate).

## overlay

ثبّت اختصارًا أو أسقطه من الشيفرة، من دون أي صفوف في قاعدة البيانات:

```php
'overlay' => [
    'navigation:App\Filament\Resources\ProductResource' => ['letter' => 'p'],
    'global:export' => ['letter' => 'x'],
    'row-action:approve' => ['letter' => 'a'],
    'navigation:App\Filament\Pages\Hidden' => ['disabled' => true],
    'table:delete' => ['disabled' => true],
],
```

كل مفتاح هو هوية هدف، بالشكل `set:key`:

| المجموعة | المفتاح | مثال |
| --- | --- | --- |
| `navigation` | صنف المورد أو الصفحة | `navigation:App\Filament\Resources\OrderResource` |
| `global` | اسم إجراء الترويسة | `global:export` |
| `row-action` | اسم إجراء الصف المسجّل | `row-action:approve` |
| `table` | سلوك من سلوكيات الجدول | `table:delete` |

سلوكيات الجدول هي `search` و`cursor-down` و`cursor-up` و`row-down` و`row-up` و`page-prev`
و`page-next` و`select` و`edit` و`delete` و`cursor-release`. الروابط المخصّصة تخصّ المشرف ولا
يمكن استهدافها من الـ `overlay`.

كل مُدخل إمّا `['letter' => 'r']`، الذي يفرض ذلك الحرف، وإمّا `['disabled' => true]`، الذي
يزيل الاختصار. يُزال الاختصار المعطَّل قبل إسناد الأحرف، فيعود حرفه
إلى المجمّع.

يتغلّب الـ `overlay` على الأعراف، وهذا ما يجعله الأداة المناسبة لمفتاح تحتاج إلى تثبيته في الشيفرة،
والأداة غير المناسبة للتفضيلات. ويتغلّب تعطيل الـ `overlay` أيضًا على تعديل المشرف نفسه؛ أمّا الحرف المثبّت
فلا، لذا فإن المشرف الذي يعيد تعيين ذلك الاختصار يحصل على حرفه هو. انظر
[كيف تتضافر الطبقات](customization.md#how-the-layers-combine).

تثبيت حرف يشغّل أيضًا إجراء الترويسة الذي يعمل عند الضغط نفسه، والذي لا يحصل عادةً على مفتاح
على الأحرف المجرّدة. لا تثبّت مثل هذا الإجراء إلا إذا كان تشغيله بضغطة عَرَضية مقبولًا.

### الأحرف المفروضة

تثبيت الـ `overlay` والحرف المخزَّن في خريطة المشرف كلاهما حرف مفروض. ويتبعان القواعد
نفسها:

- **ليس ضمن a–z:** يُتجاهَل. يحتفظ الاختصار بحرفه التلقائي، ولا يستطيع مُدخل خاطئ واحد أن يعطّل
  خريطة المفاتيح.
- **مفتاح محجوز في ذلك المجمّع** (`G` أو `J` أو `K` أو مفتاح جدول آخر بين المفاتيح المجرّدة): يُتجاهَل
  بالطريقة نفسها.
- **مفتاح يحمله اختصار مُسنَد إليه حرف تلقائيًا:** يأخذه الحرف المفروض، وينتقل الاختصار
  الآخر إلى حرف آخر متاح.
- **مفتاح يحمله حرف مفروض آخر:** الأول في ترتيب المجمّع يحتفظ به ويفقد اللاحق
  مفتاحه. ترتيب المجمّع هو التنقّل قبل الروابط المخصّصة، وإجراءات الترويسة قبل إجراءات الصفوف.

تُسنَد أحرف إجراءات الصفوف المسجّلة قبل تطبيق الـ `overlay`، لذا تُعدّ أحرفها مفروضة. انظر
[إجراءات الصفوف](row-actions.md#how-letters-are-assigned) لمعرفة ما يعنيه ذلك عند تثبيت أحدها. وتحقّق من
ورقة الاختصارات بعد إضافة التثبيتات.

## cache

```php
'cache' => ['ttl' => 86400],
```

المدة، بالثواني، التي تُخزَّن فيها خريطة المفاتيح الخاصة باللوحة كلها (التنقّل والروابط المخصّصة) في الـ `cache`.
أمّا اختصارات الصفحة نفسها فرخيصة وتُحسب عند كل تصيير.

الغرض من هذه المدة استعادة المساحة، لا ضمان الحداثة. مفتاح الـ `cache` هو بصمة لما يلي:

- معرّف اللوحة؛
- التنقّل: الموارد والصفحات المسجّلة، مع عناوينها وترتيب فرزها؛
- هوية الخريطة الفعّالة وإصدارها (كل تغيير محفوظ يرفع الإصدار)؛
- إعدادات المطوّر التي تشكّل الخريطة: `overlay` و`modifiers` والمفاتيح التي يحجزانها؛
- اللغة المحلية (`locale`)؛
- صيغة الـ `cache` الخاصة بالحزمة.

أي تغيير في أحد هذه العناصر يؤدّي إلى مفتاح مختلف، فلا تُقدَّم خريطة قديمة. ولا يتضمّن المفتاح
هوية الطالب: المشرفون على الخريطة نفسها يتشاركون مُدخلًا واحدًا. ما لا تستطيع البصمة فعله هو حذف
المُدخل الذي ابتعدت عنه، وكل تعديل أو عملية نشر تمسّ التنقّل تترك واحدًا خلفها. وهذه
المدة هي ما يستعيد تلك المُدخلات.

`null` يخزّن إلى الأبد. لا تختره إلا على مخزن تديره بنشاط، وتوقّع أن يكبر فضاء المفاتيح
مع عدد التعديلات التي يجريها مشرفوك.

## rowActions

ليس مفتاح إعداد: تُسجَّل إجراءات الصفوف على الإضافة عبر `->rowActions([...])`. انظر
[إجراءات الصفوف](row-actions.md).
