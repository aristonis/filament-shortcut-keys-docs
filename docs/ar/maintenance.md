# تقليم التجاوزات الميتة

التجاوز المخزَّن (إعادة تعيين أو تعطيل أجراه مشرف، أو أجراه إعداد مسبق) مفتاحه هو صنف الهدف أو اسمه،
لا الـ `slug` أو العنوان، لذا ينجو من إعادة التسمية وإعادة الترتيب. لكنه لا ينجو من الحذف: احذف
موردًا أو صفحة أو إجراء صف مسجّلًا، فتبقى الصفوف التي أعادت تعيينه مشيرة إلى لا شيء.
لا ضرر منها، لكنها تتراكم. نظّفها بالأمر:

```bash
php artisan shortcut-keys:prune
```

## الخيارات

```bash
php artisan shortcut-keys:prune --dry-run       # list what would be removed, delete nothing
php artisan shortcut-keys:prune --panel=admin   # audit one panel (repeat the option for several)
php artisan shortcut-keys:prune --force         # skip the confirmation in production
```

| الخيار | الأثر |
| --- | --- |
| `--dry-run` | يطبع التقرير ويخرج دون حذف. |
| `--panel=` | يفحص معرّفات اللوحات المحدّدة فقط. ومن دونه تُفحص كل لوحة تسجّل الإضافة. ومعرّف اللوحة غير الموجود، أو الذي لا تستخدم لوحته الإضافة، يفشل بخطأ. |
| `--force` | يحذف دون سؤال، حتى عندما تكون البيئة بيئة إنتاج. |

يطبع الأمر دائمًا ما وجده قبل حذف أي شيء: جدولًا بمعرّف الخريطة والهدف لكل
تجاوز يتيم، وعددَ التجاوزات التي تركها دون مساس. وفي بيئة الإنتاج يطلب
التأكيد ما لم يُمرَّر `--force`.

يرفع الحذف إصدار كل خريطة متأثرة ضمن المعاملة (`transaction`) نفسها، فتتوقّف خرائط المفاتيح المخزّنة مؤقتًا التي ما زالت
تحمل التجاوزات المحذوفة عن التقديم.

## ما يستطيع الحكم عليه وما لا يستطيع

لا يحكم الأمر إلا على الأهداف التي يستطيع سردها خارج طلب ويب:

- أهداف التنقّل: الموارد والصفحات المسجّلة في اللوحة؛
- إجراءات الصفوف: الأسماء المسجّلة عبر `->rowActions([...])`؛
- سلوكيات الجدول الثابتة.

تُحذف تجاوزات ما لم يعد موجودًا من هذه الأهداف.

أمّا تجاوزات إجراءات الترويسة والروابط المخصّصة فيُبلَّغ عنها وتُترك في مكانها. إجراء الترويسة لا
يوجد إلا أثناء تصيير صفحته، لذا لا تستطيع عملية الصيانة التمييز بين إجراء محذوف وإجراء
غير موجود ببساطة في الصفحة التي تنظر إليها، والربط المخصّص يخصّ المشرف الذي أنشأه.
والحذف بناءً على التخمين سيُتلف بيانات حيّة، لذا لا يفعله الأمر.

لإزالة أحد هذه التجاوزات، استدعِ `EditUserMap::enable()` لذلك الهدف نيابةً عن مالكه (انظر
[التحكم بها من الشيفرة](custom-bindings.md#driving-it-from-code))، فيُسقط الصف ويرفع
إصدار الخريطة. وإذا حذفت صفوفًا من `shortcut_map_entries` بنفسك، فارفع `version` الخاص بالخريطة في
المعاملة نفسها؛ ومن دون ذلك تستمر خريطة المفاتيح المخزّنة مؤقتًا في تقديم الصف القديم.

## متى تشغّله

بعد إزالة مورد أو صفحة أو إجراء صف مسجّل، أو كمهمة مجدولة من حين لآخر:

```php
// routes/console.php
Schedule::command('shortcut-keys:prune --force')->weekly();
```
